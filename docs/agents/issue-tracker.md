# Issue tracker: Trello

Las tareas y especificaciones de este repositorio viven en el tablero Trello [TPO Ingeniería de Software – Grupo 03](https://trello.com/b/6ad535e55e476bc89a6f8be9).

## Convenciones

- Una tarjeta de Trello equivale a un issue o spec.
- El flujo es `Por hacer` → `En curso` → `A validar` → `Completado`.
- Los títulos siguen el formato `<EDT> – <resultado>` cuando la tarea pertenece a la estructura de desglose del trabajo.
- Cada tarjeta debe identificar responsable, dependencias, checklist de aceptación y enlaces a evidencia.
- Las skills deben leer y actualizar la tarjeta existente; no deben crear un issue paralelo en GitHub.
- Cuando una skill diga "publicar en el issue tracker", debe crear o actualizar una tarjeta en este tablero siguiendo estas convenciones.
- Si no hay una integración autenticada disponible para Trello, debe preparar el contenido y solicitar al usuario que realice la operación manual, sin trasladar silenciosamente el trabajo a otro tracker.
