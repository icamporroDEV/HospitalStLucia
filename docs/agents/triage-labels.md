# Triage Labels

Las skills hablan en términos de cinco roles canónicos de triage. Este archivo mapea esos roles a las etiquetas que deben usarse en Trello.

| Label in mattpocock/skills | Label in our tracker | Meaning                                   |
| -------------------------- | -------------------- | ----------------------------------------- |
| `needs-triage`             | `needs-triage`       | Requiere evaluación del responsable       |
| `needs-info`               | `needs-info`         | Espera información adicional               |
| `ready-for-agent`          | `ready-for-agent`    | Especificada y lista para un agente       |
| `ready-for-human`          | `ready-for-human`    | Requiere implementación o decisión humana |
| `wontfix`                  | `wontfix`            | No se implementará                         |

Cuando una skill mencione un rol, debe usar la etiqueta correspondiente de la segunda columna.
